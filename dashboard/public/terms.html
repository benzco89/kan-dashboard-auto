Kan News Social Media Analytics Dashboard

Last updated: January 2025

1. Purpose

This application is an internal analytics dashboard developed for Kan News (Israeli Public Broadcasting Corporation) to monitor and analyze social media performance metrics.

2. Usage

This dashboard is intended for internal use by authorized Kan News staff members only. The application collects and displays analytics data from connected social media platforms for reporting and optimization purposes.

3. Data Collection

The application collects publicly available metrics from social media platforms including but not limited to: views, likes, shares, comments, and follower counts.
