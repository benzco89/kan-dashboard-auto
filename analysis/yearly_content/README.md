# ספירת תוכן שנתית — פייסבוק ואינסטגרם

מה פורסם בעמודים, כמה ומאיזה סוג — 2025 מול 2026. ספירה בלבד, בלי מטריקות.

## הקבצים

| קובץ | מה יש בו |
|---|---|
| `yearly_content.csv` | הנתון הגולמי: שורה לכל פריט שפורסם מ-2025-01-01 — `platform, date, type` (16,204 שורות נכון ל-2026-08-10) |
| `monthly_counts.csv` | פיבוט חודשי: `platform, month, type, count` — הבסיס הנוח לפילוחים והשוואות |
| `summary_2025_vs_2026.md` | הסיכום: טבלאות ההשוואה והמסקנות |
| `monthly_2025_vs_2026.md` | חודש מול חודש + ניתוח חודשי האירועים של 2025 + אימות מול הגיליון |

## מאיפה הנתונים

הסקריפט `yearly_content_probe.py` (בשורש הריפו) מדפדף ישירות על ה-Graph API —
`/published_posts` של עמוד הפייסבוק ו-`/media` של חשבון האינסטגרם — ולא על
הגיליונות (שמכסים רק מאז שהפייפליין קם). קריאה בלבד, שום כתיבה לגיליונות.

סיווג הסוגים בפייסבוק זהה ל-`facebook_collector.detect_media_type`; באינסטגרם
לפי `media_product_type` (רילס) ו-`media_type` (תמונה/קרוסלה/וידאו).

## לרענן את הנתונים

```bash
gh workflow run probe_yearly_content.yml --ref main
# כשנגמר:
gh run download <run-id> --name yearly-content --dir analysis/yearly_content
```

## מה אין כאן — ולמה

- **סטוריז**: ה-API של מטא חושף סטוריז רק בזמן שהם חיים (24 שעות). אין רשימה
  היסטורית, ולכן אין השוואה שנתית. האיסוף העצמאי שלנו ("סטוריז אינסטגרם")
  מתחיל רק ב-2026-07-05.
- **וידאו בפייסבוק אחרי אמצע 2025**: מטא מפרסמת מאז כל וידאו כרילס. בהשוואות
  לאורך זמן יש לאחד `Video` + `Reel` לרצף אחד — אחרת נראה כאילו הווידאו נעלם.
